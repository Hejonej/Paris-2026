# 여행 중 매일 이어지는 완료·미방문 재배치 UX

2026-11-14 사용자 여행 방식에 따른 설계. 이번 변경에서는 설계만 확정하고 완료 상태 저장/자동 이동을 구현하지 않는다. 현재 AI 기능은 ADD-only이므로 재배치를 중복 추가로 흉내내지 않는다.

## 핵심 원칙

여행 계획은 출발 전에 끝나는 문서가 아니라 마지막 날까지 수정하는 도구다. 빡빡한 계획 자체를 실패로 취급하지 않는다. 하루에 방문한 곳은 완료의 만족감을 주고, 못 간 곳은 삭제되지 않은 다음 선택으로 남긴다.

## 일정 중 완료 체크

- 각 장소의 시간축 점 옆에 독립된 44pt 체크 목표. 장소명 탭/태그/경로 버튼과 분리한다.
- 체크 시 작은 체크 애니메이션과 짧은 햅틱, ‘완료’ 표시. 취소할 수 있고 장소명/주소는 계속 읽힌다. 완료 후 경로·사진·기록으로 진입 가능하다.
- 날짜 요약에 ‘오늘 4/7곳 방문’. 식사·휴식의 빈 자리, 이동 구간, 체크인/비행기 블록은 장소 방문 달성 수에 섞지 않는다.
- 완료 체크는 실제 방문일과 연결한다. 기록을 자동 공개하거나 글을 작성하지 않는다.

## 하루 마무리: 사용자가 시작

1. 일정 하단 ‘오늘 정리’ → 완료 4곳 / 아직 방문하지 않은 3곳 요약 시트.
2. 미방문 장소마다 ‘다음 일정으로 옮기기’, ‘일단 보관’, ‘이번엔 가지 않기’ 선택. 단순 미체크를 미방문 확정으로 간주하지 않으며, 실제 방문했다면 여기서 완료 처리 가능.
3. 옮길 장소를 복수 선택하고 ‘남은 날짜에 나눠 배치’. 기본 대상은 선택한 날 다음 날부터 여행 종료일. 오늘 남은 시간도 원하면 포함한다.
4. AI는 남은 각 날짜의 기존 방문 수·자유 시간·체류 시간·숙소·항공/예약·선호 이동방식을 고려해 고르게 분산한다. 같은 장소는 한 번만 배치하고 완료한 장소/고정 예약은 이동하지 않는다. 실제 이동시간/영업시간이 미연결이면 사실로 주장하지 않는다.
5. 미리보기: ‘A · 20일 15:00 → 22일 11:00’, ‘B · 보관 유지 · 넣을 시간 부족’. 바뀌는 항목과 그대로인 항목을 분리한다. 확인 전 원래 일정은 변하지 않는다.
6. ‘선택한 변경 적용’ 한 번으로 이동. 직후 되돌리기 제공. 일부 불가능하면 가능한 변경만 선택 적용하고 나머지는 보관한다.

## 보호 규칙

- 기존 완료/예약/사용자 잠금 항목은 고정. 원래 MUST의 날짜·시간은 임의로 바꾸지 않는다. 사용자가 옮길 대상으로 명시적으로 선택한 MUST만 시간 이동을 제안할 수 있고 MUST 속성은 유지한다.
- 현재 ADD-only 보호를 우회하지 않는다. 후속 구현에는 이동 전용 제안 타입과 원본/대상 일정의 동시 검증, 버전 충돌 검사, 일괄 적용/되돌리기 트랜잭션이 필요하다.
- 항목의 안정된 ID와 출처·태그·주소·메모를 유지한다. 옮긴 항목을 새 방문 복제본으로 만들지 않는다.
- 원래 날짜에는 ‘22일로 옮김’ 이력만 남기며 활성 일정/방문 수로 중복 집계하지 않는다. 이동 이력은 오늘의 완료 목록과 구별한다.
- 제안 생성 이후 사용자가 완료/시간/예약을 변경하면 이전 이동 제안 적용을 막고 재계산한다.

## 반복과 마지막 날

- 같은 미방문 장소를 여러 날에 걸쳐 다시 선택할 수 있다. 자동으로 매일 밀거나 알림을 강요하지 않는다.
- 마지막 날도 ‘오늘 정리’를 제공한다. 오늘 남은 시간이 있고 비행기/체크아웃 제약 안에서 가능하면 그 시간만 제안한다.
- 여행 종료 이후 날짜를 몰래 만들지 않는다. 더 이상 넣을 시간이 없으면 ‘다음 여행을 위해 보관’, ‘이번엔 가지 않기’, ‘여행 기간 수정’ 중 선택한다.
- 보관은 장소/원본/메모를 유지한다. 다른 여행으로 넘길 경우 대상 여행을 명시적으로 고르고 실제 도시가 다른 장소도 경고 없이 복제하지 않는다.
- 기록에는 실제 완료한 장소가 중심이며, 미방문 목록은 조용히 별도 보관한다. 완주율로 죄책감을 유도하지 않는다.

## 후속 구현 검증 기준

완료 취소/재실행 보존, 같은 장소의 반복 이월, 마지막 날 잔여 시간, 밤 비행기, 다중 숙소, 잠긴 MUST, 부분 수용, 생성 중 상태 변경, 중복 클릭, 일괄 실패/되돌리기, 원본 출처·커스텀 태그 유지. 실제 iOS/Android에서 터치 목표와 스와이프 충돌 확인.
