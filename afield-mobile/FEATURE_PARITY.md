# 기존 웹 → 모바일 복원 범위

이번 작업은 전체 앱의 재설계가 아니라 빠진 핵심 흐름의 복원입니다.

- 복원: GeoNames 세계 도시 오프라인 검색/국가 자동 입력, 달력 날짜 선택, Instagram JSON 파일 선택/컬렉션/미리보기/분류/선택/중복 제외/원본 보관/장소 후보 확인.
- 개선: 웹의 날짜 목록 31개 제한과 모바일의 31일 입력 제한 제거. 기간 외 기존 일정은 삭제하지 않고 변경 거부.
- 보호: 가져오기/장소 후보 확인으로 기존 계획을 초기화하던 웹 코드는 이식하지 않음. 원본 게시물과 후보 장소를 구분하고 출처를 유지. 위치 확인과 일정 배치는 별도 동작.
- 연결했으나 외부 장애: 기존 Cloudflare `/places-match`의 요청/응답 UI. 실제 공개 장소 조회에서 Google 권한 오류(HTTP 502)를 확인함. 서버/키/배포 수정은 하지 않음. 지도에서 사용자가 직접 확인하는 흐름 제공.
- 미이식: 항공·숙소 입력, Buy list, AI 일정 생성/수정, 앱 내 실제 이동 시간 계산, 기록 작성.
- 보류: ‘구상 중/준비 중’의 의미를 알기 쉽게 바꾸는 작업.
- 남은 검증: 실제 사용자 JSON의 내보내기 변형과 iPhone Files/Google Maps 왕복. 자동 테스트의 합성 JSON을 실제 사용자 파일 검증으로 간주하지 않음.

- 추가: 챕터 관리에서 수정·삭제·복원, 생성 버튼 단일화, Instagram 설명용 그림 가이드. 사용자 원본 saved_collections.json의 파싱 실패를 재현/수정했고 16개 비어 있지 않은 컬렉션/301개 게시물을 확인. 원본은 저장소에 포함하지 않으며 실제 기기 파일 선택 재확인은 남아 있음.
