# 사용자 피드백 및 후속 작업

- 2026-10-25: ‘구상 중’과 ‘준비 중’의 차이가 날짜 유무라는 것을 사용자가 알아보기 어렵다는 피드백. 사용자가 **지금은 변경하지 말고 나중에 개선**하도록 요청함. 상태 이름/판정은 이번 작업에서 유지한다. 추후 상태의 의미가 드러나는 문구나 날짜 표시와 함께 검토한다.
- 후보 탭의 기기 빈 화면 보고는 자동 컴포넌트 테스트에서 재현되지 않았음. 처리 보강 후 기기 재확인 결과는 아직 받지 못함. 해결 확정으로 기록하지 않는다.

# 다음 단계: 여행 정보 편집

날짜 미정 여행에 날짜를 추가하고 이름/도시/기간을 수정한다. 기존 일정 날짜를 자동으로 옮기지 않는다. 일정이 있는 날짜를 제외하는 기간 변경은 거부한다. 겹치는 날짜의 일정, MUST, 후보 및 다른 여행은 보존한다.

# 합의된 이동 UX

- 탭은 여행 안의 주요 영역이며 여행 목록 이동을 항상 제공한다. 상세/수정은 뒤로가기를 제공한다.
- 장소 옆은 한 줄 설명·현재 위치에서 경로 찾기, 장소 사이는 구간별 이동수단·이 구간 경로 찾기.
- 도보가 기본이며 구간마다 대중교통/차로 바꿀 수 있다.
- 이름만 있는 일정은 실제 방문지를 선택하도록 정확한 일정 이름으로 안내한다. 마레 산책은 다음/이전 확인 장소를 고려한 제한된 규칙으로 시작점을 추천하고 변경할 수 있게 한다. 기존 일정/MUST를 임의로 다른 장소로 바꾸지 않는다.
- 이동 시간은 실제 제공자 응답이 있어야 표시한다. 이번에는 API를 연결하지 않고 Google Maps에서 확인하도록 안내한다.

# 기존 핵심 기능 복원

도시 검색/국가 자동 입력과 달력 선택을 신규·수정 양쪽에 복원한다. 웹의 내부 31일 잘림을 사용자 요구사항으로 보지 않고 모바일 입력/날짜 생성 제한도 제거한다.

Instagram 가져오기는 원본 게시물과 장소 후보, 실제 위치 확인과 일정 배치를 분리한다. 원본 URL/캡션/컬렉션을 보존하고 이름 추출만으로 장소를 확정하지 않는다. 기존 일정 초기화 코드는 이식하지 않는다. 원래의 AI 최적화·항공·숙소·Buy list까지 모바일 완료라고 부르지 않는다.

기존 장소 확인 API에 공개 장소 1개 조회 결과 Google 권한 오류(HTTP 502)를 확인했다. 배포·키·운영 데이터는 바꾸지 않고 직접 지도 확인 경로를 제공한다.

일정 분류는 자동 추정 후 사용자가 태그를 눌러 수정하며 저장한다. 쇼핑·관광·식사·카페/디저트·숙소·이동·기타를 사용한다.
